# 🏋️‍♀️ Sistema de Gestión de Gimnasio - "Cuerpo Sano"

Proyecto académico desarrollado para la materia **Ingeniería de Software I** en la **Universidad Nacional Arturo Jauretche**. El sistema "Cuerpo Sano" automatiza los procesos administrativos del gimnasio "Su mejor peso", facilitando la gestión de miembros, clases, entrenadores y pagos.

---

## 🚀 Funcionalidades Principales

### 👤 Gestión de Miembros
- Registro, modificación, consulta y eliminación de miembros
- Generación de carnet con código de barras
- Registro de membresías (mensual, anual, etc.)
- Aplicación de descuentos para estudiantes y adultos mayores

### 📅 Gestión de Clases y Actividades
- Registro y modificación de horarios
- Inscripción de miembros a clases específicas
- Asignación de entrenadores certificados
- Control de asistencia mediante lector de código de barras o huella digital

### 💳 Gestión de Pagos
- Registro de pagos por adelantado
- Control de vencimientos (30 días por membresía mensual)
- Generación de reportes de ingresos

### 📊 Reportes
- Reportes de asistencia por miembro y por clase
- Reportes de ingresos por membresía

---

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML, CSS, JavaScript (React opcional)
- **Backend**: Node.js / Express (según implementación)
- **Base de Datos**: JSON local (prototipo) o MySQL (versión escalable)
- **Compatibilidad**: Windows 11, Android, navegadores Chrome, Edge y Opera

---

## 📁 Como abrir el sistema
- Descargar el archivo, descomprimirlo.
- Abrirlo en el editor de codigo deseado
- Luego en la terminar del editor instalar las dependencias con el comando: npm install
- Luego activar el servidor mediante el comando: npm run server
- Finalmente para abrir el proyecto en el navegador escribir el comando: npm run dev
